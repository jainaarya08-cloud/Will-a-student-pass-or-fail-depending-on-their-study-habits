# Will-a-student-pass-or-fail-depending-on-their-study-habits
--- DATA CLEANING ---

Utilisied LabelEncoder to convert categorical, 'Pass' or 'Fail' data into numerical output by mapping it to unique integer values.(1s and 0s)

Checked for any null values, output is clean as all 0s. 

--- ML TECHNIQUES ---

-Logisitic Regression: predict the probability(%) of passing then maps to the final 0/1 decision. 

-Linear Regression: predict a students score based on the hours studied.
